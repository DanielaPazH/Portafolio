## Caso de estudio: Alke Wallet Web MVC

### Descripción del proyecto

El objetivo fue desarrollar una aplicación web sencilla que permitiera realizar operaciones básicas de una billetera digital, aplicando conocimientos de programación orientada a objetos y arquitectura MVC.

### Desafío principal

El principal desafío consistió en integrar diferentes componentes de una aplicación web: la lógica de las operaciones financieras, el controlador de las solicitudes y la interfaz utilizada por el usuario.

### Solución desarrollada

Organicé la aplicación utilizando tres componentes principales:

- **Cuenta.java:** administra el saldo y las operaciones de depósito y retiro.
- **WalletServlet.java:** procesa las solicitudes realizadas por el usuario.
- **index.jsp:** presenta la interfaz y los resultados de las operaciones.

### Herramientas utilizadas

Java, Eclipse, JSP, Jakarta Servlets, Apache Tomcat, Git y GitHub.

### Resultados obtenidos

La aplicación permitió implementar y probar tres funcionalidades principales:

1. Consultar el saldo disponible.
2. Realizar depósitos.
3. Efectuar retiros, verificando la disponibilidad de saldo.

También se incorporaron mensajes para informar el resultado de las operaciones y validar entradas incorrectas.

Estos resultados corresponden a pruebas funcionales del proyecto, no a métricas de uso en producción.

### Principales aprendizajes

- Comprender la separación de responsabilidades mediante MVC.
- Aplicar programación orientada a objetos.
- Procesar solicitudes HTTP mediante Servlets.
- Conectar una interfaz JSP con la lógica de una aplicación.
- Utilizar Git y GitHub para publicar un proyecto.

### Habilidades técnicas aplicadas

Programación en Java, organización de código, resolución de errores, desarrollo web introductorio y control de versiones.

Elegí Alke Wallet Web MVC porque representa un avance importante en mi proceso de formación. Me permitió integrar conocimientos que había trabajado por separado y comprender cómo se relacionan los distintos componentes de una aplicación funcional.
